## 如何使用本融合手册

两来源描述的是**同一类技术目标**（VPS 上跑 **VLESS + Reality**），但**安装路径完全不同**：

| 路线 | 名称 | 适合人群 | 核心特征 |
|------|------|----------|----------|
| **路线甲** | **XrayR 一键脚本**（Issue #94） | 希望尽量少手工配置、在 SSH 里跟着菜单走完 | **一条 bash** 拉取 `XrayR-release/install.sh`，交互生成节点 |
| **路线乙** | **3x-ui 面板**（Netlify 2026 篇） | 希望有 **Web 后台**、可视化管理流量与多用户 | **一条 bash** 安装 `mhsanaei/3x-ui`，浏览器里配 **443 + Reality** |

**请勿在同一条 VPS 上混装两套面板/脚本而不清环境**，除非你明确知道如何卸载与排端口冲突。新手**二选一**即可。

## 第一部分：共同前置（两路线通用）

### 1.1 账号与支付

- 境外 VPS 需要邮箱注册与支付方式（信用卡/PayPal/支付宝等视厂商而定）。
- Netlify 原文对「礼品卡/代充/成品邮箱」描述较多；Issue #94 未展开——**风险自负**，见合规声明。

### 1.2 系统镜像与规格（融合建议）

| 项目 | Issue #94 | Netlify 2026 | **融合建议** |
|------|-----------|--------------|--------------|
| 系统 | Ubuntu 22.04 **或 Debian 11** | **Ubuntu 22.04 或 24.04** | 优先 **Ubuntu 22.04 LTS**（两路线兼容性最好）；若只用 3x-ui 可选用 24.04 |
| 规格 | 最低档（示例 **512MB**） | **1GB**（$5–6/月档） | **1GB 更稳妥**跑面板与 Xray；极简脚本路线 512MB 可能仍可用但余量小 |

### 1.3 区域与 IP（重点融合）

- **Issue #94**：列举东京、首尔、新加坡、美西等，**未强调**某厂商东京「连坐」风险。
- **Netlify 2026**：明确建议**避开 Vultr 东京**，倾向美西/新加坡/**大阪**；ping 不通可重建换 IP。

**融合结论**：选机房时以**延迟测速**为准；若使用 **Vultr**，可**优先尝试非东京**或按 Netlify 建议换区域；IP 被墙时**换 IP/重建**是通用手段。

### 1.4 SSH 登录（两路线相同）

本机终端执行（`你的服务器IP` 换成公网 IP）：

```bash
ssh root@你的服务器IP
```

首次连接输入 `yes`；密码输入**不回显**。成功标志：`root@hostname:~#`。

### 1.5 建议：安装前更新系统（融合补强）

Issue #94 **明确要求**先 `apt update/upgrade`；Netlify 网页**未写**此步。为减少依赖问题，**两路线均建议在首次 SSH 后执行**：

```bash
apt update -y && apt upgrade -y
```

非 Debian/Ubuntu 请改用对应包管理器（不在两文范围内）。

## 第二部分：路线甲（Issue #94 · XrayR 脚本）

**适用**：接受命令行交互；不需要 Web 面板。

### 2.1 安装 curl（若缺）

```bash
apt install curl -y
```

### 2.2 执行一键脚本

```bash
bash <(curl -Ls https://raw.githubusercontent.com/XrayR-project/XrayR-release/master/install.sh)
```

### 2.3 交互要点（与 Issue 一致）

- 选择安装 **Xray/XrayR** 相关项；**启用 Reality**；无域名则 IP 回车；**BBR 建议 Y**；端口可用默认。
- 终端输出的 **`vless://`、UUID、公钥、SNI** 等全部备份。

### 2.4 可选：补装 BBR（Issue 原文）

```bash
wget --no-check-certificate https://github.com/teddysun/across/raw/master/bbr.sh && chmod +x bbr.sh && ./bbr.sh
```

## 第三部分：路线乙（Netlify · 3x-ui 面板）

**适用**：需要中文 Web 后台、入站与流量可视化管理。

### 3.1 安装面板

```bash
bash <(curl -Ls https://raw.githubusercontent.com/mhsanaei/3x-ui/master/install.sh)
```

按提示设置**面板用户名、密码、面板端口**（10000–65000）。

### 3.2 放行面板端口

在云厂商 **Security Group / Firewall** 放行 TCP **面板端口**；本机若启用 `ufw` 可：

```bash
ufw allow <面板端口>/tcp
ufw reload
```

### 3.3 浏览器配置

访问 `http://<VPS_IP>:<面板端口>`，在 **Inbounds** 添加：

- Protocol **vless**；Port **443**；开启 **Reality**  
- Dest `www.microsoft.com:443`；SNI `www.microsoft.com`  
- 使用 **Get New Cert** 生成密钥  

复制 **`vless://`** 到客户端。

## 第四部分：客户端与验证（合并两来源）

### 4.1 桌面 Windows

| 来源 | 推荐客户端 |
|------|------------|
| Issue #94 | **NekoRay**、**v2rayN** |
| Netlify 2026 | **v2rayN**、**Clash Verge Rev** |

**融合**：**v2rayN** 为交集；另可按需选用 NekoRay 或 Clash Verge Rev。导入方式均以 **剪贴板 `vless://`** 为主。

### 4.2 Android

| 来源 | 推荐 |
|------|------|
| Issue #94 | **NekoBox**、Clash for Android |
| Netlify 2026 | **v2rayNG** |

**融合**：**v2rayNG** 与 **NekoBox** 均可，请使用**较新**版本并确认支持 **Reality**。

### 4.3 iOS

两来源均指向 **Shadowrocket**（美区等外区 ID）；Netlify 写明约 **$2.99**；Issue #94 另提 **Stash、Quantumult X** 等——以你客户端实际支持为准。

### 4.4 macOS

Issue #94：**NekoRay**、**ClashX Pro**；Netlify 未单独展开 macOS——可沿用 **NekoRay** 或选用 **Clash** 系客户端（需确认 Reality 支持）。

### 4.5 验证方式

| 来源 | 验证 |
|------|------|
| Issue #94 | 访问 Google / YouTube 等 |
| Netlify | `https://whatismyipaddress.com` 对比 VPS IP |

**融合**：**出口 IP 与 VPS 一致**是最直接判据；再按需访问业务站点做二次确认。

### 4.6 时间同步（Netlify 强调）

若出现证书/时间相关报错，校准本机时间，**与标准时间误差建议小于 1 分钟**。

## 第五部分：运维与排错（摘录合并）

- **系统更新**：`apt update -y && apt upgrade -y`
