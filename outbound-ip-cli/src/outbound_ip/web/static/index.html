技术说明与 TSV（原始行）

本页不向远端 POST；脚本直链 audit-core.js，与下方 TSV 同源。 地址栏顶层打开探测站点（整页跳转）不适用跨域脚本限制；本页用 fetch 读正文时，若站点未返回允许跨源的响应头（示例：cip.cc），状态码常为 000，摘要中会显示类似「请求失败（网络异常、跨域限制或浏览器拦截）」， 与你在地址栏单独打开是否正常无关。 通过 outbound-ip serve 同源打开时，可对仅限内置探测 URL调用 /__probe，由本机代取正文，以便读出无跨域响应头的站点； file:// 打开的页面不能使用该代取。各探测单次约有 20s 前端超时，避免站点挂起导致按钮长期停在「检测中」。

终端一键路径对每次 curl 使用 --noproxy '*'，与浏览器的代理策略不同，属预期差异。
